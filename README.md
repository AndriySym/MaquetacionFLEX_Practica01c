# Descripción del proyecto

Este proyecto es una demostración de maquetación web utilizando técnicas de diseño flexibles con CSS Flexbox. El objetivo es mostrar cómo organizar el contenido de una página de manera eficiente y atractiva.

## Contenido de la Publicación

El proyecto incluye una página web estructurada con las siguientes secciones:
- Un encabezado con el título del proyecto.
- Un menú de navegación.
- Una galería de imágenes organizada en filas flexibles.
- Un pie de página con información de contacto y licencias.

## Desarrollo del Proyecto

Este proyecto fue diseñado utilizando las siguientes tecnologías:
- **HTML5** para la estructura.
- **CSS3** con flexbox para el diseño y disposición de los elementos.

El código incluye un diseño centrado, una navegación intuitiva y una galería con imágenes descriptivas. Todas las imágenes están bajo una licencia adecuada.
